## 데이터 검사 상세

한국어와 영어가 함께 들어 있는 생성된 테스트 이미지 1장을 ML Kit 한국어 모델로 인식했다. `쿠폰` 분류, `2026-09-30` 날짜, 날짜 미확인, 알림 없음, 원본 파일 보관을 검증했다. 같은 이미지를 다시 가져왔을 때 동일 카드의 중복으로 반환됨을 확인했다.

`../../` 경로 탈출 ZIP을 거부하고 기존 자료 개수가 유지됨을 확인했다. 정상 백업을 기존 보관함에 복원했을 때 중복이 추가되지 않음을 확인했다. 테스트 자료를 삭제한 후 백업을 복원하고 원본 이미지 바이트 일치, 새 카드 ID, 알림 꺼짐을 확인했다.

이 테스트 이미지 1장의 성공을 실제 사용자 스크린샷 전체의 인식 정확도로 해석해서는 안 된다.

## UI 검사와 화면 증거

빈 보관함 → 사용자가 예시 추가 → 쿠폰 필터 → 가려지지 않은 카드 상단을 터치 → 상세 편집 → 제목 수정 → 저장 → 저장 파일을 새 Repository로 읽기 → Activity 재생성 후 표시를 확인했다.

이전 검사에서는 카드 아래쪽 텍스트 터치 후 편집 입력란을 찾지 못했다. 마지막 검사는 실제 터치가 카드 선택 상태로 이어졌는지 먼저 확인하도록 수정했고, 모든 검사를 통과했다. 실패 기록을 삭제하거나 검사를 건너뛰어 성공 처리하지 않았다. OCR·백업 검사는 UI 검사와 독립적으로 실행된다.

`Screenshot-Inbox-validation` 아티팩트에는 단위 테스트 보고서, Lint 보고서, 두 native 테스트 출력, 실제 화면 PNG, APK 권한, 프로세스 재실행 화면·UI 구조가 포함된다.

## 아직 검증되지 않은 범위

실제 갤러리 공유 앱별 동작·Photo Picker 다중 선택, Samsung 등 제조사별 알림 전달, 알림 거부·채널 차단, 절전·재부팅·시간대 변경, Android8~16 전체 기기 호환성, 저메모리·저장 공간 부족, 500개 대량 자료, 다양한 실제 이미지 인식률, TalkBack·큰 글자·다크 모드·원본 확대 제스처는 추가 검증이 필요하다.
