# 검증 기록과 점검 범위

## 로컬에서 수행한 검사

`Core.kt`와 `tools/ParserCheck.kt`를 Kotlin 컴파일러로 컴파일하고 실행: **29개 검사 통과**.

한국어·영어 날짜, 실제 달력 날짜 검증, 윤년, 쿠폰 기간의 종료일, 행사 기간의 시작일, 연도 생략 안내, 지난 연도 유지, 가격과 날짜 구분, 안전한 링크, 위치·제목 추출, 확인 필요 상태, 완료·만료 제외를 포함한다.

## GitHub Actions에 구성한 검사

`CoreTest`: 동일한 29개 단위 테스트.
Android Lint와 Debug APK 빌드.
`AppSmokeTest`: 새 설치 화면 → 예시 가져오기 → 제목 수정 → Activity 재생성 후 유지 → 실제 기기 내 한국어 OCR → 파일 해시 중복 감지 → 경로 탈출 ZIP 거부 → 백업 중복 병합 → 전체 복원과 원본 바이트 일치.
UI 화면을 에뮬레이터에서 캡처해 검증 결과 아티팩트에 포함한다.

**구성한 검사와 실제 성공 결과는 구분해야 한다. Actions 실행의 결론과 개별 테스트 보고서가 최종 근거다.**

## 아직 추가 검증이 필요한 부분

Samsung 등 제조사별 실제 기기 알림 전달, 알림 권한 거부/채널 차단, 절전·재부팅·시간대 변경, Android8~16 실제 호환 범위, 저메모리·저장공간 부족, 500개 대량 데이터, 다양한 스크린샷의 OCR 정확도, TalkBack과 큰 글자, 상세 화면 원본 확대, 스토어용 고정 서명과 런처 아이콘.

자동 기한 추출·알림을 법적·금전적 기한의 유일한 근거로 사용하지 않는다.
