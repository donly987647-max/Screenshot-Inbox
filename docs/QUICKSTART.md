# 캡처함 0.1.0 시작하기

이 파일은 Android 개발 버전 사용 안내입니다. 스토어에 출시된 정식 버전이 아닙니다.

## 설치와 첫 사용

Android 8.0 이상 기기에서 제공된 APK를 엽니다. 출처가 확인된 이 파일을 직접 설치하려는 경우에만 사용 중인 브라우저/파일 앱의 외부 앱 설치 권한을 허용하세요. 설치가 끝나면 해당 권한을 다시 끌 수 있습니다. 기존 버전이 있다면 먼저 앱 설정에서 ZIP 백업을 만드세요.

앱에서 **첫 스크린샷 가져오기**를 누르거나, 갤러리에서 이미지를 선택한 후 **공유 → 캡처함**을 선택합니다. 처음에는 쿠폰 한 장으로 시작하세요. 최대 20장을 한 번에 가져올 수 있습니다.

인식이 끝나면 원본과 제목·분류·날짜를 비교합니다. 틀린 부분은 직접 수정합니다. **원본 크게 보기**에서는 두 손가락 또는 확대 버튼으로 글자를 확인할 수 있습니다. 날짜는 `YYYY-MM-DD` 형식입니다. 연도가 없는 원본에서는 앱이 제안한 연도를 반드시 확인하세요.

날짜 확인 항목을 체크한 뒤 필요한 경우 당일·1일 전·3일 전 알림을 선택하고 저장합니다. 알림을 처음 설정하면 Android의 알림 허용 여부를 묻습니다. 허용하지 않아도 원본 저장과 검색은 사용할 수 있습니다.

**보관함**에서는 제목뿐 아니라 인식된 본문도 검색합니다. **다가오는**에서는 남은 쿠폰·일정을 날짜순으로 봅니다. 사용한 카드는 상세 화면에서 완료로 표시합니다. 앱에서 카드를 삭제해도 갤러리의 원본은 삭제하지 않습니다.

## 자료 보관

원본과 내용은 앱 전용 공간에 저장됩니다. 별도의 계정·AI API 키를 입력할 필요가 없습니다. 이미지 분석에 서버를 사용하지 않습니다. 링크 열기, 캘린더 추가, 원본 공유, ZIP 내보내기를 선택하면 사용자가 지정한 외부 앱으로 해당 정보가 전달됩니다.

**설정 → 원본 포함 ZIP 백업**으로 원본 포함 ZIP을 저장할 수 있습니다. ZIP은 암호화되지 않습니다. 쿠폰 번호, 주소, 개인 대화 등이 포함될 수 있으므로 안전한 장소에 보관하고 공개적으로 공유하지 마세요.

앱 삭제 또는 앱 데이터 초기화 시 내부 자료가 삭제됩니다. Debug APK의 서명은 빌드 환경에 따라 달라질 수 있어 새 APK의 업데이트 설치가 거절될 수 있습니다. 재설치하기 전에 ZIP 백업을 완료하세요.

## 알아둘 제한

글자 인식·자동 분류·날짜 추출은 틀릴 수 있습니다. 특히 긴 캡처, 작은 글자, 장식체, 여러 날짜가 있는 이미지에는 원본 대조가 필요합니다. 법적·금전적 기한은 이 앱의 알림에만 의존하지 마세요.

알림은 Android의 절전·권한·제조사 설정에 따라 지연되거나 차단될 수 있습니다. 기기 시간대를 변경했다면 알림을 다시 저장하세요. 백업에서 복원한 알림은 꺼진 상태이므로 다시 설정해야 합니다.

갤러리를 전체 자동 감시하는 기능, 가격 추적, 클라우드 동기화, iPhone 버전, 결제는 포함하지 않습니다. 기본 보관 한도는 500개, 이미지 20MB/장, 백업 200MB입니다.
