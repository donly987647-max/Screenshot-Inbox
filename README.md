# 캡처함 · Screenshot Inbox

스크린샷을 **다시 찾고, 제때 사용하는 카드**로 바꾸는 Android 앱.

> 저장한 순간을, 다시 쓸 순간으로.

## v0.1.0

- 사진 선택기 또는 **갤러리 공유 → 캡처함**으로 최대 20장 가져오기
- 앱에 포함된 한국어 ML Kit 모델로 기기 내 글자 인식
- 쿠폰·일정·상품·장소·메모 분류, 제목·날짜·가격·링크 추출
- 원본 미리보기·확대, 글자 검색, 분류 필터, 제목·가격·날짜 수정, 사용 완료, 원본 공유
- 사용자가 확인한 날짜만 알림에 사용; 당일·1일 전·3일 전 선택
- 캘린더 앱에 일정 추가, 글자 복사
- 앱 전용 저장공간에 원본과 목록 보관, SHA-256 중복 감지
- 원본 포함 ZIP 백업, 기존 자료를 유지하는 복원
- 로그인·광고·결제·외부 AI API 키 없음

자동 추출은 규칙 기반이며 결과가 틀릴 수 있습니다. 날짜는 기본적으로 `확인 필요` 상태입니다. **실제 기한은 원본과 직접 확인하세요.**

## 실행

Android 8.0(API26)+ / compile·target SDK36 / JDK17 / Gradle8.14.3.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Gradle Wrapper를 저장소에 포함합니다. 사용 방법과 설치 안내는 `docs/QUICKSTART.md`에 있습니다.

APK: `app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions는 단위 테스트·Lint·APK 빌드 후 Android15 에뮬레이터에서 화면 조작·편집, 저장 파일 재읽기, 실제 한국어 OCR, 중복 방지, 백업/복원, 악성 ZIP 거부를 검사하도록 구성했습니다. 2026-09-21 실행 `35557340363`에서 **단위 테스트 29개 + native 통합 검사 2개, APK 빌드가 통과**했습니다. Lint는 오류 0개·경고 17개입니다. 정확한 범위와 미검증 항목은 `docs/VALIDATION.md`를 확인하세요.

## 기술 구성

Kotlin / Jetpack Compose / Material3 / bundled ML Kit Korean / WorkManager / atomic JSON / app-private image files. 추론 서버나 인증 백엔드를 운영하지 않습니다.

## 개인정보와 한계

INTERNET 권한을 제거하며, 전체 갤러리 읽기 권한도 요청하지 않습니다. 사용자가 선택·공유한 이미지만 가져옵니다. 자동 클라우드 백업과 기기 간 자동 이전은 비활성화합니다.

기본 한도는 500개 카드, 이미지 한 장 20MB, ZIP 백업 200MB입니다. 카드 목록은 8MB까지 저장합니다. 백업은 암호화되지 않으며 이미지·인식한 글자를 모두 포함합니다. 안전한 곳에 보관해야 합니다.

앱을 삭제하거나 데이터를 지우면 로컬 자료가 삭제됩니다. 복원은 기존 카드를 유지하고 중복 원본을 건너뜁니다. 복원한 알림은 다시 설정해야 합니다. 예약은 설정 당시 기기 시간대를 기준으로 계산하며 절전·권한·제조사 설정에 따라 지연·차단될 수 있습니다. 표준시간대 변경 후에는 알림을 다시 저장하세요.

OCR은 글자만 읽습니다. 이미지의 장면·제품명·위치를 모두 이해하는 범용 AI가 아닙니다. 연도 생략, 여러 날짜, 작은 글자, 장식 폰트와 긴 스크린샷의 인식 품질은 원본 확인이 필요합니다. 지도 API, 가격 추적, 전체 갤러리 자동 감시, iOS 공유 확장, 결제는 이 버전에 없습니다.

## 배포 상태

0.1.0은 **개발용**입니다. Debug APK는 정식 스토어 서명본이 아니고, 빌드 환경이 바뀌면 서명 키도 달라질 수 있습니다. 업데이트 설치가 거부되면 먼저 ZIP 백업을 만든 뒤 재설치해야 합니다. 스토어 출시에는 고정 서명 키, 런처 아이콘, 접근성·실기기·배터리 검증, 개인정보처리방침과 데이터 안전성 신고가 별도로 필요합니다.

제품 범위·수익화 가설은 `docs/PRODUCT.md`, 점검 항목은 `docs/VALIDATION.md`에 있습니다.
