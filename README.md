# 캡처함 · Screenshot Inbox

스크린샷을 **다시 찾고, 제때 사용하는 카드**로 바꾸는 Android 앱.

> 캡처는 쉽게. 다시 쓰기는 더 쉽게.

## v0.1.0 개발 범위

- 사진 선택기 또는 갤러리의 **공유 → 캡처함**으로 가져오기
- 앱에 포함된 한국어 ML Kit 모델로 기기 내 글자 인식
- 쿠폰 / 일정 / 상품 / 장소 / 메모 분류, 제목·날짜·가격·링크 추출
- 원본 이미지와 추출 결과 확인·수정, 검색, 사용 완료 처리
- **사용자가 확인한 날짜만** 만료 알림에 사용
- 개인 앱 저장공간에 보관, 원본 포함 ZIP 백업·복원

로그인, AI API 키, 유료 추론 서버, 광고, 결제는 첫 버전에 없습니다. 기획 및 구현 중인 개발 버전이며 실제 완료·검증 내역은 후속 커밋에 기록합니다.

## 제품 원칙

1. 전체 갤러리를 몰래 읽지 않습니다. 사용자가 선택하거나 공유한 이미지만 가져옵니다.
2. 추출 결과는 정답이 아닙니다. 날짜는 확인 필요 상태로 저장하고 알림 전 확인을 받습니다.
3. 콘텐츠를 서버로 보내지 않습니다. 인터넷 권한을 제거한 Android 앱으로 구현합니다.
4. 예시 데이터는 사용자가 직접 선택한 경우에만 보여줍니다.
5. 판매 가능성은 가설입니다. 유료 기능보다 실제 스크린샷의 인식 품질과 재사용 흐름을 먼저 검증합니다.

## 기술 구성

Kotlin · Jetpack Compose · Material 3 · bundled ML Kit Korean text recognition · WorkManager · app-private atomic JSON and original image storage.

Android 8.0(API26)+. compile/target SDK36. JDK17, Gradle8.14.3.

## 실행 / 검증

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

개발 APK는 스토어 배포용 서명본이 아닙니다. Google Play 출시는 별도의 서명·스토어 정책 점검·실기기 품질 검증 후 진행합니다.

## 제한

- 자동 분류는 글자 인식과 규칙 기반입니다. 범용 멀티모달 AI의 장면 이해와 다릅니다.
- 연도가 없거나 날짜가 여러 개인 캡처는 반드시 원본과 비교해야 합니다.
- 안드로이드 절전·알림 설정 때문에 예약 알림이 지연되거나 차단될 수 있습니다.
- 앱 삭제 시 로컬 자료가 삭제됩니다. 중요한 자료는 ZIP으로 백업해야 합니다.
- 법적·금전적 기한을 이 앱의 추출 결과나 알림에만 의존하지 마세요.
